# CodexPad Implementation Plan

> **For agentic workers:** Core behavior is test-first; iPad-only APIs require Xcode/iOS SDK verification on macOS.

**Goal:** Deliver a runnable iPadOS Xcode project for local-folder AI-assisted code editing.

**Architecture:** A SwiftUI app owns a security-scoped workspace and a Responses API agent. The platform-neutral core is also exposed as a Swift Package so safety-critical behavior can be tested outside Xcode.

**Tech Stack:** Swift 6, SwiftUI, Foundation, UniformTypeIdentifiers, Security, OpenAI Responses API.

**Spec:** `docs/superpowers/specs/2026-09-11-codexpad-design.md`

## Global Constraints
- iPadOS 18+ only.
- No third-party dependencies.
- Mutating AI tools review-gated by default.
- Workspace-relative paths only; block traversal and symlink escapes.
- API keys never committed or stored in UserDefaults.
